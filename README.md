# SanBazar shopping-agent

AI-консультант по каталогу SanBazar (подбор, сравнение, корзина, вопросы про
доставку/самовывоз) поверх [anthropics/commerce-agents](https://github.com/anthropics/commerce-agents)
(закреплено на коммит `fd4d59224ab96b43c6dc6888207c67b3bd5a24cf`).

Отдельный сервис от сайта (Next.js/Vercel) — сайт обращается к нему по HTTP.

## Что настоящее, а что заглушка

- **Поиск, карточка товара** — реальные, читаются из Sanity напрямую (GROQ),
  кэш на 60 секунд.
- **Корзина** — рабочая, но только в памяти процесса: пропадает при
  перезапуске сервиса, ничего не пишет в Sanity. Нормально для одного
  небольшого процесса; если понадобится переживать рестарты — нужно вынести
  в отдельное хранилище (см. `sanbazar/api/sanbazar_backend.py`).
- **История заказов** — всегда пустая: на сайте нет личного кабинета.
- **Политики (доставка/оформление)** — три коротких текста, которые я написал
  вручную по тому, что знаю о SanBazar (`_POLICIES` в `sanbazar_backend.py`).
  Не настоящие юридические формулировки — стоит перечитать и поправить.

## Локальный запуск

```bash
python -m venv .venv
.venv/Scripts/activate   # Windows; на Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # заполнить ANTHROPIC_API_KEY и SANITY_READ_TOKEN
uvicorn sanbazar.api.main:app --reload --port 8000
```

Проверка: `curl http://127.0.0.1:8000/api/health` — должен показать
`"products": <настоящее число>`.

## Деплой на Railway/Render

1. Запушить этот репозиторий на GitHub.
2. В Railway/Render создать новый сервис "Deploy from GitHub repo".
3. Платформа сама увидит `requirements.txt` и `Procfile` — ничего вручную
   настраивать не нужно, кроме переменных окружения ниже.
4. Задать переменные окружения (в панели сервиса, НЕ в коде):
   - `ANTHROPIC_API_KEY` — ваш ключ Anthropic
   - `SANITY_PROJECT_ID` — `70uy4yts`
   - `SANITY_DATASET` — `production`
   - `SANITY_READ_TOKEN` — **новый** токен с ролью **Viewer** (только чтение),
     создать отдельно в Sanity → Manage → API → Tokens → Add API token.
     Не переиспользуйте токен записи, которым пользуется сам сайт — этому
     сервису запись не нужна вообще.
   - `ALLOWED_ORIGINS` — `https://sanbazar.com` (домен сайта, без слеша в конце)
5. После деплоя платформа даст публичный URL вида `https://<имя>.up.railway.app`
   (или аналог на Render) — это и есть адрес API для чат-виджета на сайте.

## Известные ограничения на будущее

- Один процесс/воркер: несколько инстансов молча разделят сессии и корзины
  между собой (см. предупреждение в `sanbazar/api/main.py`). Для текущего
  масштаба сайта это не проблема.
- `demo_common/` — скопированный (не подключённый как зависимость) код из
  примера `retail` в справочном репозитории Anthropic — авторы прямо пишут,
  что справочная реализация не поддерживается, так что это осознанный слепок,
  а не то, что будет само обновляться.
